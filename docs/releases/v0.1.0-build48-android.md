# LumaLex Android 0.1.0 — build 48

## 简体中文

LumaLex Mobile 首个 Android GitHub Release，发布现有的正式签名 build 48 APK，并提供中英双语介绍、使用说明与 Android 实机截图。本次文档更新未重新编译安装包。

### 下载与安装

- 安装包：`LumaLex-0.1.0-build48-arm64-v8a.apk`。
- 系统：Android 7.0（API 24）及以上；架构：ARM64 / `arm64-v8a`。
- 版本：`0.1.0`，build `48`；APK versionCode 为 `2048`（含 Flutter ABI 偏移）。
- 包名：`com.lumalex.dictionary`。
- 签名：正式 RSA 签名，已通过 APK Signature Scheme v2 验证，非 Android Debug 证书。
- 下载下面 Assets 中的 APK，在手机上打开安装；源码 ZIP/TAR 不是安装包。

### Android 功能

- 导入自己的 MDX/MDD 词典，离线查词与音频资源读取。
- 词典分组、查找范围、启用状态和排序管理。
- 在词条正文左右滑动切换有结果的词典，点词典名称直接选择。
- 在支持标准文字操作菜单的应用中选词，通过“LumaLex 查词”打开可拖动、缩放的查词浮窗。
- 收藏、搜索历史、词汇卡复习、字号调整和学习数据导出/恢复。
- 手机与宽屏布局；本地诊断报告。

## English

The first Android GitHub release for LumaLex Mobile publishes the existing release-signed build 48 APK, with bilingual documentation and Android screenshots. The documentation update does not rebuild the package.

### Download and install

- Installer: `LumaLex-0.1.0-build48-arm64-v8a.apk`.
- Requires Android 7.0 (API 24) or later on ARM64 / `arm64-v8a`.
- Version `0.1.0`, build `48`; APK versionCode `2048` includes Flutter's ABI offset.
- Application ID: `com.lumalex.dictionary`.
- Release RSA signature verified with APK Signature Scheme v2; not signed with an Android Debug certificate.
- Download the APK from Assets below and open it on Android. Source ZIP/TAR files are not installers.

### Android features

- Import your own MDX/MDD dictionaries for offline lookup and dictionary audio.
- Dictionary groups, lookup scopes, enabled state and ordering.
- Swipe horizontally on the article to switch dictionaries with results, or select from the dictionary-name list.
- Open a movable, resizable lookup window through “LumaLex 查词” in compatible Android text-action menus.
- Favorites, history, vocabulary review, text-size controls and learning-data export/restore.
- Phone and wide layouts, with local diagnostic reports.

[English overview](https://github.com/memetics1980/lumalex-mobile/blob/main/README_EN.md) · [Android user guide](https://github.com/memetics1980/lumalex-mobile/blob/main/docs/USER_GUIDE.en.md)

**Platform and data notes**: iOS / iPadOS remains in development and has no installer in this release. Supply your own dictionaries; no dictionary files are bundled. Text-selection lookup depends on the source app and is not OCR. This Android version does not include desktop AI contextual definitions. Phone and desktop data do not synchronize automatically. In-place updates require matching signatures; export records you want to retain before uninstalling.
